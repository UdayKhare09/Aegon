All benchmarks are conducted under strict hardware isolation: server processes are pinned to physical cores 0 and 1, and the load generator is pinned to cores 2 through 5. Results are the arithmetic mean of three independent 10-second runs with a 3-second warm-up and 2-second cooldown between runs.

## HTTP/3 over QUIC

This suite evaluates HTTP/3 over QUIC (RFC 9000 / RFC 9114) with 100 connections and 10 concurrent streams each. Only Aegon and Swerver implement HTTP/3 in this comparison.

| Workload | Aegon req/s | Swerver req/s | Aegon mean lat | Aegon p50 | Aegon p99 |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Plaintext | 336,440.73 | 109,570.60 | 2.98 ms | 2.66 ms | 5.15 ms |
| JSON | 331,608.03 | 109,342.50 | 3.02 ms | 2.70 ms | 5.41 ms |
| Dynamic route | 326,682.63 | 108,137.93 | 3.10 ms | 2.78 ms | 6.06 ms |

Aegon is approximately 3.0x faster than Swerver across all HTTP/3 workloads, with 3.0x lower mean latency and 4.3x to 5.3x lower p99 tail latency.

Reproduce a single run:

```bash
./benchmarks/http3/run_single.sh aegon plaintext 10s 100 10
```

## Application stack benchmarks

The `benchmarks/appstack` directory contains end-to-end workloads that exercise JSON serialization, database queries, and asynchronous delays.

### Baseline HTTP/1.1 (GET and POST)

Results at 512 connections and 4096 connections, averaged across three runs:

| Workload | Connections | Aegon req/s | Actix req/s | Swerver req/s |
| :-- | :-: | :-: | :-: | :-: |
| GET /baseline11 | 512 | 508,435.15 | 387,632.79 | 451,428.68 |
| GET /baseline11 | 4096 | 406,585.06 | 309,782.60 | 359,364.64 |
| POST /baseline11 | 512 | 511,694.06 | 368,609.26 | 436,246.57 |
| POST /baseline11 | 4096 | 403,482.36 | 297,860.60 | 340,888.47 |

### Async delay endpoint

The `/delay/10` endpoint simulates a 10 ms async sleep. At 512 connections, Aegon achieves 50,362 req/s versus Actix at 42,722 req/s. At 4096 connections, Aegon and Actix are nearly tied (233,769 vs 238,617 req/s). Swerver does not implement this upstream pattern.

### JSON serialization

Plain JSON responses at 512 and 4096 connections:

| Connections | Aegon req/s | Actix req/s | Swerver req/s |
| :-: | :-: | :-: | :-: |
| 512 | 265,279.98 | 138,524.37 | 198,155.55 |
| 4096 | 191,686.86 | 122,953.32 | 176,596.12 |

Gzip-compressed JSON at 512 and 4096 connections:

| Connections | Aegon req/s | Actix req/s | Swerver req/s |
| :-: | :-: | :-: | :-: |
| 512 | 113,777.79 | 56,406.56 | 26,626.15 |
| 4096 | 95,877.60 | 56,151.84 | 25,626.67 |

### Database query workload

The database benchmark issues a parameterized SQL query against PostgreSQL. Aegon sustains 25,595 req/s at 512 connections and 24,330 req/s at 1024 connections with zero errors. Actix achieves 17,234 req/s at 512 connections and 16,757 req/s at 1024 connections. Swerver returns a high error rate (over 87% 503 responses) under this load.

## How to reproduce

All benchmark suites are self-contained under `benchmarks/`. Each suite includes shell scripts and Python runners.

```bash
# HTTP/1.1 plain
python3 benchmarks/http1_plain/run_triplicate.py aegon plaintext 10s 100

# HTTP/1.1 TLS
python3 benchmarks/http1_tls/run_triplicate.py aegon json 10s 100

# HTTP/2
python3 benchmarks/http2/run_triplicate.py aegon plaintext 10s 100 10

# HTTP/3
python3 benchmarks/http3/run_triplicate.py aegon plaintext 10s 100 10

# Full application stack
python3 benchmarks/appstack/run_baseline.py
python3 benchmarks/appstack/run_json.py
python3 benchmarks/appstack/run_db.py
python3 benchmarks/appstack/run_async.py
```
